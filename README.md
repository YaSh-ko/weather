# 🌤️ Weather App

Простое и удобное веб-приложение для отображения текущей погоды в любом городе мира.

## 📌 Описание

Weather App позволяет пользователю быстро узнать актуальные погодные условия выбранного города. Приложение отображает:  

- Температуру воздуха  
- Описание состояния погоды (солнечно, облачно, дождь и т.д.)  
- Влажность и давление  
- Ветер (скорость и направление)  

Приложение использует открытые API для получения актуальных данных о погоде и обновляет их в реальном времени.

## 🛠️ Используемые технологии

- **HTML** — структура и разметка веб-страницы  
- **CSS** — стилизация интерфейса и адаптивная верстка  
- **JavaScript** — логика приложения, работа с API и обновление данных на странице  
- **Fetch API** — получение данных о погоде с внешнего сервера  

## ⚡ Особенности

- Быстрый и простой интерфейс  
- Поддержка поиска городов по всему миру  
- Отображение ключевых параметров погоды в одном окне  
- Возможность легко расширять функционал (например, добавление прогноза на несколько дней)  

## 🚀 Установка и запуск

1. Клонируйте репозиторий:  

   ```bash
   git clone https://github.com/YaSh-ko/weather.git
   ```
2. Перейдите в папку проекта:
  ```bash
  cd weather
  ```
3. Откройте файл index.html в любом современном браузере.
4. Наслаждайтесь приложением и проверяйте погоду в любом городе!
